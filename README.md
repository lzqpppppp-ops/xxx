# Jev 剪贴板

**一个在聊天应用旁边使用的 Android 悬浮对话助手。**

当你不知道怎么理解对方的一句话，或者想换一种更合适的表达时，可以把消息交给 Jev。它会结合你保存的这段对话，给出对方可能的意思、建议回复和更温和的回复。情绪判断只是推测，最终怎么回复，由你决定。

> 当前版本：2.6。应用仍在迭代；请以实际安装测试结果为准。

## 能做什么

- **分开保存对话**：顶部点 `+` 新建对话，下面点击名字快速切换；长按名字可重命名、修改目的、删除或调整这段对话的语气范围。
- **可选谈话目的**：新建时可以写「完成合同签订」或「约出来吃饭」，留空则沿用普通分析。长按对话名可随时修改或清空目的，例如合同完成后改为「维护客户关系」。模型只在氛围与时机合适时才自然带出目的。
- **分析上下文**：保存对方的消息及分析结果；长按记录可插入双方以前说的话，或删除单条记录。分析时使用当前对话最近的消息作为上下文。
- **生成可选回复**：查看两种建议，选中后复制到剪贴板。你在聊天应用中粘贴、确认并发送。
- **自由配置模型**：在桌面应用中保存多个兼容 Chat Completions 的模型配置，在悬浮窗中切换。
- **调整悬浮窗**：拖动顶部横条移动窗口，拖动底部两角调整大小；点击窗口外自动收起为悬浮按钮；支持深色界面。窗口尺寸和界面选择会保留。

Jev 不会读取微信聊天标题，不会自动识别聊天对象，也不会代你点击输入框或发送消息。使用悬浮窗需要系统的“显示在其他应用上层”权限，**不需要无障碍权限**。

## 如何使用

1. 安装并打开桌面上的「Jev 剪贴板」。点「管理模型」，填写配置名称、完整的 HTTPS Chat Completions 接口地址、模型名称和 API Key。API 服务由你自己选择；应用不提供模型调用额度。
2. 点「打开悬浮窗」，按系统提示授予悬浮窗权限。
3. 在聊天页面打开悬浮窗，点顶部 `+` 新建对话，按需填写「谈话目的」（可留空）；再次点 `+` 可添加更多对话。点下面的名字切换当前对话，长按名字可重命名、修改目的或删除；菜单底部双端滑条可设置这段对话的语气范围。默认覆盖「温和」至「疯狂」，此时不额外限制模型语气；缩小范围后仅在下次分析时作为语气指导，仍受模型本身的安全限制。切换聊天对象时，记得先切换这里的对话。
4. 将对方的新消息输入或粘贴到标有「对话名的新消息」的消息框，点「分析并生成选项」。你可以查看可能的意思和两种回复。
5. 点击想用的回复。Jev 会复制文字并收起面板；回到聊天输入框粘贴，确认聊天对象和文字，再手动发送。

点击悬浮窗外会收起为悬浮按钮。顶部圆形 `=` 按钮切换模型，月亮或太阳按钮切换深色界面，`−` 收起面板，`×` 关闭悬浮窗。长按消息记录可以从剪贴板插入旧消息，或删除这条记录。分析期间可切换对话；切回后尚未选择的回复选项会恢复。点开未选择的历史分析仍可选一次回复；选中后其他选项清除，历史分析仅保留「可能的意思」和被选中的回复，不再显示另一条建议或单独的选择按钮。2.5 及更早的已选历史无法自动判断用户选的是哪条，点开这类记录可手动指定保留哪条。长按分析文字仍可用系统文字选择。

## 数据与隐私

聊天记录和模型配置保存在应用的本地私有数据中。点击分析时，当前对话中作为上下文的文字及已填写的谈话目的会发送到你配置的 API 服务；请留意服务提供方的数据处理政策，不要把敏感内容发送给不信任的接口。API Key 也保存在本机的应用数据中，**目前没有额外加密**。卸载应用会删除本地记录和配置；删除一段对话会删除其本地记录。

情绪与意图分析可能出错，不宜把结果当作对方真实想法的证明。发送前请自己核对回复。

## 构建 APK

这个项目当前提供适合手机操作的 GitHub Actions 构建文件 `android.yml`，其中内嵌了 Android 工程：

1. 将 `android.yml` 上传至仓库的 `.github/workflows/android.yml`，覆盖旧文件并提交。
2. 打开仓库 **Actions → Build Jev Android APK**，等待运行成功。也可以从该工作流页面手动触发。
3. 在这次运行的 **Artifacts** 下载 `JevClipboard-debug-apk`，解压后安装 `app-debug.apk`。

构建使用 Java 17、Android SDK 35、Android Gradle Plugin 8.7.3 和 Gradle 8.9；最低支持 Android 8.0。这里生成的是 **debug APK**，不等同于签名发布版。

## 当前边界

- 需手动选择本地对话；不会随微信联系人自动切换。
- 需自行提供有效的 API 配置及相应服务的可用额度。
- 选择回复只会复制文本，发送由用户完成。
- 目前没有云同步或对话导出功能。
